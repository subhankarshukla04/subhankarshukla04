### Subhankar Shukla

Final-year Finance student at Rotman Commerce, University of Toronto, and a Level II Candidate in the CFA Program. Since August 2026 I've been on the valuations team at Qapita in Singapore, working on 409A and ESOP valuations for venture-backed companies. I'm available in Toronto from January 2027.

Most of these started as a real problem: something slow at work, a case for an interview, a class project.

| Project | What it does |
|---|---|
| [Axiom](https://github.com/subhankarshukla04/Axiom-Valuations) | Equity research tool. Blends comps, a DCF and consensus into one fair value, and lists every assumption so you can check it before trusting the number. |
| [Cap Table Reconciler](https://github.com/subhankarshukla04/cap-table-reconciler) | Cleans a client's cap table before a valuation starts: 60 rule checks, the preference waterfall and a live-formula Excel workpaper. |
| [Finance Digest](https://github.com/subhankarshukla04/finance-digest) | The market close I read every night. Rates, FX, commodities and the headlines behind the moves, published automatically since March 2026. |
| [Sentinel](https://github.com/subhankarshukla04/sentinel) | Safeguards screen for carbon-credit due diligence: Indigenous consent, NGO complaints and litigation risk, every signal cited. |
| [Wego Earnings Digest](https://github.com/subhankarshukla04/wego-earnings-digest) | Reads travel-company earnings calls and pulls out what matters for a regional OTA's strategy team. |
| [Counter](https://github.com/subhankarshukla04/counter) | Price tracking for independent cafés in Singapore, built from 96 real menus with a team at NUS. |
